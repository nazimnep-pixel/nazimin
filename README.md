# nazimin (CadProfi AZ — clean-room)

Azerbaijani-language CAD add-on–style project, implemented **from scratch**. Targets (long term): architectural, mechanical, HVAC/piping, and electrical workflows; symbol libraries; DXF/DWG exchange; optional integration with host CAD programs.

This repo does **not** incorporate CADprofi source code, installers, or proprietary symbol libraries.

## Status

Greenfield — planning and architecture sketch only. See [`docs/architecture.md`](docs/architecture.md).
